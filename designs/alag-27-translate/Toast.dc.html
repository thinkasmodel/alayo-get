③ 右键菜单（页面空白处）③ Right-click menu (page background)

Chrome 的规则：同一扩展在当前位置有两项以上时，自动收进一个以扩展名命名的子菜单。所以加了「并翻译」后，页面空白处右键多一层。开了「保存时总是翻译」时隐藏这一项，「存入 Alayo Get」本身就会翻译，菜单回到一项、不分层。浏览器不支持本机翻译时不创建这一项。菜单文字带上当前默认语言，改设置时跟着更新。（子菜单行为实现时在真实 Chrome 里核对。）Chrome rule: when one extension has two or more items in the current context, they are grouped under a submenu named after the extension. So adding “and translate” puts the page items one level deeper. With “Always translate when saving” on, the item is hidden (“Save to Alayo Get” already translates), so the menu goes back to one top-level item. Not created when the browser can’t translate. The item names the current default language and updates when it changes. (Submenu behavior to be checked in real Chrome during implementation.)
