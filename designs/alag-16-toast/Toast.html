页面提示改版：批注不再在网页里输入

安全审计 S1：网页脚本能从键盘事件里读到页面提示里输入的批注。方案是去掉页内输入框，「加批注」改为打开工具栏面板，在扩展自己的文档里输入。下面两版只差按钮文案，面板本身不改。

Security audit S1: page scripts can read notes typed inside the on-page toast. The textarea moves out of the page; "Add note" now opens the toolbar popup. The two versions differ only in the button label; the popup itself is unchanged.

边界：面板没能打开

不自动消失 · 带关闭

Chrome 只允许在当前活动窗口打开面板；窗口失焦或 Chrome 版本太旧时调用会失败。此时提示不收起，下面加一行 11 号 --t2 小字说明怎么办，不用 danger 色（与「没能写入批注」的处理一致）。按钮保留，可以再点。注意：工具栏图标是「打开即保存」，对刚存过的页面会落到「已存过」态而不是编辑态，所以这里不引导去点图标。

Chrome only opens the popup in the active window; the call fails when the window is unfocused or Chrome is too old. The toast stays, with one 11px line in --t2 telling the user what to do, no danger color.
