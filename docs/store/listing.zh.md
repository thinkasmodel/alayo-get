## 名称

Alayo Get

## 简短说明

```text
把网页、X 帖子与作者串、图片、视频和摘录存成普通的 Markdown 与媒体文件，直接写进你选定的本地文件夹。
```

## 类别

工作效率（Productivity），建议值。

## 详细说明

```text
Alayo Get 把你在网上看到的内容存成电脑上一个文件夹里的普通文件：文章、帖子、链接和摘录存成 Markdown，图片、视频、音频和 PDF 保留原文件。

文件归你，不归某个应用
- 存下来的是带 YAML frontmatter 的普通 Markdown 和原始媒体文件，不绑定任何笔记软件。
- 用浏览器的 File System Access API 直接写进你选定的本地文件夹，不经过下载目录，也不会每存一次就弹一次保存对话框。

能存什么
- 文章：网页正文转成 Markdown，图片一并存到本地。正文抽取用开源引擎 defuddle。
- X 帖子：单帖、X 长文和引用帖。同一作者连续自回复的作者串自动拼成一篇。
- 书签：链接、标题、描述和封面。正文抽不出来时退回书签，保存不算失败。
- 图片、音频、视频和 PDF：原样保存文件本身，另附一个小的元数据文件，记下它来自哪个网页。
- 在线视频（YouTube、B 站、X 视频、网盘分享页）：存成一个 Markdown 文件，记封面、时长、作者、简介和链接。
- 摘录：选中文字保存。同一页面的摘录汇进同一个文件，每条都带文本片段链接（#:~:text=），点开就跳回原文对应位置。

怎么保存
- 工具栏按钮、右键菜单（页面、链接、图片、视频、音频、选中文字），或快捷键 Alt+Shift+S。
- 存完可以补标题、标签和批注。
- 已经存过的页面会被认出来：提示上次保存的日期，也可以另存一份新快照。
- 界面跟随浏览器语言，显示简体中文或英文。

文件存下来之后怎么用
它们就是普通的 Markdown 和媒体文件，任何编辑器、笔记工具或文件管理器都能打开。如果你用 Mac 应用 Alayo Workbench，可以把剪藏库文件夹加为监控目录：新剪藏会一篇一张卡地出现在 Workbench 里，可以在画布上整理。这一步是可选的。

隐私
所有内容只写进你选定的文件夹。没有账号、没有统计分析、没有遥测；扩展只在你保存时访问你正在保存的内容所在的网站。隐私政策：https://alayo.ai/zh/get/privacy

以 Apache License 2.0 开源：https://github.com/thinkasmodel/alayo-get
```
